# Changelog

## 0.3.0

- Added ten canonical TaskRail 3 capabilities for Telegram, Meta Ads, Twenty CRM, MainWP, WordPress, Zoho Mail, Google Sheets, Shopify Admin, advertising baselines, and advertising anomaly detection.
- Kept generic execution, state, HTTP, retry, timeout, concurrency, configuration, logging, filesystem, and idempotency primitives in TaskRail core components.
- Added deny-by-default mutation authorization contracts for integrations that can change external systems.


## 0.2.0

- Updated compatibility baseline to TaskRail 3.0.0 / `3.0.x` publication contracts.
- Updated generated/scaffolded artifacts to target TaskRail 3 rather than 2.0.x.
- Strengthened local compatibility, security and contract checks for TaskRail 3.

## 0.1.0

- Initial ecosystem foundation.
