# meta-ads

Canonical Meta Marketing API capability for account, campaign, ad set, ad and insights operations.

## Purpose

Reusable Meta Ads API access without embedding advertising business decisions.

## Operations

- `listCampaigns`
- `listAdSets`
- `listAds`
- `getInsights`
- `getObjectStatus`
- `updateBudget`
- `updateStatus`

No credentials are stored by this capability. Runtime callers supply authorization material through process/runtime configuration.
