# shopify-admin

Reusable Shopify Admin API integration for product, order, customer and inventory operations.

## Purpose

Canonical Shopify Admin technical integration for TaskRail automations.

## Operations

- `graphql`
- `getProducts`
- `getOrders`
- `updateProduct`
- `adjustInventory`

No credentials are stored by this capability. Runtime callers supply authorization material through process/runtime configuration.
